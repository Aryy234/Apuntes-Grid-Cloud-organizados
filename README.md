# Computación Grid y Cloud

Apuntes de clase organizados por temas, con ejemplos, comandos y prácticas de AWS.

## Ver los apuntes en línea

**[Abrir los apuntes en la web](https://apuntes-grid-cloud.vercel.app/)**

El sitio permite consultar los temas y las imágenes desde el navegador.

## Archivos del repositorio

- [Índice de temas](LEEME.md): acceso a los apuntes organizados en Markdown.
- [Apuntes de clase](Apuntes%20de%20clase.md): archivo de entrada para añadir nuevas clases por fecha.
- [Versión HTML](index.html): página publicada en Vercel.
- [Imágenes](imagenes/): material visual utilizado por los apuntes.

## Actualización

1. Añadir la clase al archivo `Apuntes de clase.md` y guardar las capturas en `imagenes`.
2. Actualizar los archivos por temas y regenerar `index.html` con ayuda del asistente.
3. Hacer commit y push a la rama conectada a Vercel para publicar los cambios.

Editar el Markdown por sí solo no regenera la página HTML.
